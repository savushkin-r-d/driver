1.2.0.0 - 12.11.2011
 - Параметры PAC автоматически обновляются на сервере при их изменении 
 (постоянные). Файл параметров хранит их в виде скрипта Lua и находится в папке
 ./drivers/Параметры PAC/ под именем "Имя_PAC".txt. Данный механизм работает при
 наличии в данной папке такого файла (его наличие проверяется при загрузке
 проекта).
 - Добавлено автовосстановление параметров PAC после их сброса (при наличии 
 файла с сохраненными ранее параметрами). 
 1.3.1.0 - 11.09.2011
 -Обработка ошибок устройств (клапана, насосы, ...).
 1.4.0.0 - 15.04.2013
 - Названия устройств в базе каналов могут начинаться с цифры (для внутренней 
 работы с ними к имени добавляется символ подчеркивания - '1V1' -> '_1V1').
 - Для работы с устройствами к PAC отсылается Lua-скрипт
 ('__1V1:set_cmd('prop', n, 'value') - для строковых значений,
 '__1V1:set_cmd('prop', n, value) - для чисел).
  1.4.0.1 - 29.06.2013   
  - Теперь выполняется полная сборка мусора Lua каждые "n" итераций получения 
 данных от PAC.
